# Gianmarco Antonacci — Portfolio

GA Studio portfolio in Italian, plain HTML, CSS and JavaScript: home, one page per service (App, Siti web, Brand identity, AI), the projects (Bloop, Merkorn, TraineeUX, Riccardo Orsini) in iPhone or browser frames, brand boards and a contact form.

- `index.html` — the whole site: the page template and a small renderer that switches between home and service pages
- `img/` — project screenshots (webp)
- `folio/` — redirects the old `/folio/` address to the home page

## Local development

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
